# 운동 타이머

타바타 · 라운드 · 스톱워치 세 가지 모드를 지원하는 운동 타이머 웹앱입니다.
Next.js(App Router) + React + TypeScript로 만들었습니다.

## 주요 기능

### 모드

| 모드 | 설정 항목 | 진행 순서 |
| --- | --- | --- |
| 타바타 | 준비 / 운동 / 휴식 / 라운드 / 사이클 / 사이클 간 휴식 / 쿨다운 | 준비 → (운동 + 휴식) × 라운드 → 사이클 간 휴식 → … × 사이클 → 쿨다운 |
| 라운드 | 준비 / 운동 / 휴식 / 라운드 / 쿨다운 | 준비 → (운동 + 휴식) × 라운드 → 쿨다운 |
| 스톱워치 | 준비 / 타임랩(목표 시간) | 준비 → 목표 시간까지 경과 시간 측정 |

- 1 라운드 = 운동 + 휴식, 1 사이클 = 설정한 라운드 전체
- 사이클 간 휴식은 사이클과 사이클 사이에만 들어갑니다.
- 0초로 설정한 구간은 건너뜁니다.

### 화면

- **타이머 숫자:** 검정색 모노스페이스 굵은 글씨
- **배경색:** 구간마다 바뀝니다. 준비는 노랑, 운동은 빨강, 휴식은 하늘색, 사이클 간 휴식은 보라, 쿨다운은 민트, 완료는 회색입니다.
- **진행 표시:** 구간이 흘러갈수록 화면 아래에서 위로 어두운 막이 차오릅니다.
- **상단 바:** 왼쪽은 초기화 버튼(타이머와 모든 설정을 0으로), 가운데는 모드 탭, 오른쪽은 시간 설정 버튼입니다.
- **하단 바:** 시작 전에는 총 운동 시간, 진행 중에는 전체 남은 시간을 보여줍니다.

### 시간 설정

- 시간 항목을 누르면 아래에서 분·초 휠 선택기가 올라오고, 위아래로 밀어 1 단위로 고를 수 있습니다.
- −/+ 버튼은 시간 항목은 1초, 횟수 항목은 1회씩 바꿉니다.
- 설정은 브라우저(localStorage)에 저장되어 새로고침해도 유지됩니다.

### 그 밖의 기능

- 구간 종료 3초 전 비프음, 구간이 바뀔 때와 운동이 끝날 때 알림음
- 일시정지 / 계속, 다음 구간으로 건너뛰기
- 진행 중 화면 꺼짐 방지 (Screen Wake Lock 지원 브라우저)

### 키보드 단축키

| 키 | 동작 |
| --- | --- |
| `Space` | 시작 / 일시정지 |
| `Esc` | 설정 화면 또는 선택기 닫기 |
| `↑` / `↓` | 선택기에서 값 변경 |
| `Enter` | 선택기에서 완료 |

## 시작하기

Node.js 20.9 이상이 필요합니다.

```bash
npm install
npm run dev      # http://localhost:3000
```

배포용 빌드:

```bash
npm run build
npm run start
```

타입 검사:

```bash
npm run typecheck
```

## 프로젝트 구조

```
src/
├── app/
│   ├── layout.tsx            # 루트 레이아웃, 메타데이터
│   ├── page.tsx              # 메인 페이지
│   └── globals.css           # 전역 스타일
├── components/
│   ├── TimerApp.tsx          # 메인 타이머 화면 (상단 바, 타이머, 하단 바)
│   ├── SettingsScreen.tsx    # 모드별 시간 설정 화면
│   └── TimePicker.tsx        # 분·초 휠 선택기
├── hooks/
│   ├── useTimer.ts           # 타이머 진행 (구간 전환, 일시정지, 건너뛰기)
│   └── useStoredSettings.ts  # 설정 저장·불러오기
└── lib/
    ├── timer.ts              # 모드·구간 정의, 구간 목록 생성, 시간 포맷
    ├── sound.ts              # Web Audio 비프음
    └── wakeLock.ts           # 화면 꺼짐 방지
```

기획 명세는 [`code_artifact.md`](./code_artifact.md)에 있습니다.
